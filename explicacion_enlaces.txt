GUIA DE ENLACES: ¿QUE ES CADA ENLACE Y QUE HACE?

Aqui tienes la descripcion detallada de los tres enlaces de tu proyecto y que funcion cumple cada uno, para que puedas explicarselos facilmente a cualquier persona o Inteligencia Artificial.

==================================================
1. TU PERFIL DE GITHUB (Tu carta de presentacion)
   Enlace: https://github.com/Felix-20100
==================================================
* ¿Que es? Es tu perfil personal en la plataforma de GitHub.
* ¿Que hace? Funciona como tu "portafolio" de programador. Muestra tu foto, tu actividad y la lista de todos los proyectos que tienes guardados en la nube.
* ¿Como describirlo? "Este es mi perfil general de GitHub".

==================================================
2. TU REPOSITORIO DE CODIGO (La carpeta del proyecto)
   Enlace: https://github.com/Felix-20100/mg400_slash
==================================================
* ¿Que es? Es el repositorio especifico donde se guarda el codigo de este proyecto.
* ¿Que hace? Aca esta almacenado el "codigo fuente" en bruto (el archivo index.html.html, el script generate_pages.ps1, las imagenes de media/, etc.). Es el lugar de donde una IA o desarrollador tiene que descargar los archivos para poder editarlos y trabajar en ellos.
* ¿Como describirlo? "Este es el repositorio con el codigo fuente de mi manual para editarlo".

==================================================
3. TU SITIO WEB EN VIVO (El manual en internet)
   Enlace: https://felix-20100.github.io/mg400_slash/
==================================================
* ¿Que es? Es la publicacion en vivo del manual (alojado a traves del servicio GitHub Pages).
* ¿Que hace? Muestra el manual tecnico terminado, interactivo y en funcionamiento, tal cual lo verian los usuarios finales en su celular o computadora. Desde aca se puede probar la interfaz y descargar como aplicacion de escritorio (PWA). No es para editar codigo, es para usar y ver la pagina web activa.
* ¿Como describirlo? "Este es el sitio web en vivo de mi manual técnico".
